## activecollab info

Show ActiveCollab server information and compatibility

### Synopsis

Read the server's application and version information and report whether
that exact version is covered by this CLI's compatibility fixtures.

```
activecollab info [flags]
```

### Examples

```
  activecollab info
  activecollab info --json
```
