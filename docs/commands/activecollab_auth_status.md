## activecollab auth status

Show the active authentication source

### Synopsis

Show whether ActiveCollab credentials are available without displaying the API token or contacting the server.

```
activecollab auth status [flags]
```

### Examples

```
  activecollab auth status
  activecollab auth status --json
```
