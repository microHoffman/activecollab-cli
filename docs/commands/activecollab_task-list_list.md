## activecollab task-list list

List task lists in a project

### Synopsis

List the task lists configured in one ActiveCollab project.

```
activecollab task-list list [flags]
```

### Examples

```
  activecollab task-list list --project 7
  activecollab task-list list --project 7 --json
```

### Options

```
  -h, --help          help for list
      --project int   project ID (required)
```
