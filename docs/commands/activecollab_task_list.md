## activecollab task list

List tasks in a project

### Synopsis

List tasks in one ActiveCollab project.

```
activecollab task list [flags]
```

### Examples

```
  activecollab task list --project 7
  activecollab task list --project 7 --json
```

### Options

```
  -h, --help          help for list
      --project int   project ID (required)
```
